# KMP migrace — fáze 3–6: `domain/` a `data/` do `commonMain`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Přesunout doménovou a datovou vrstvu do `shared/src/commonMain`, včetně výměny Retrofitu za Ktor a Room/DataStore za jejich KMP varianty — bez jediné změny chování aplikace.

**Architecture:** Postupuje se od nejméně provázaného k nejvíc: modely → konfigurace → use cases → síť → úložiště → repository. Po každém tasku aplikace kompiluje, běží a projde smoke průchodem. iOS target musí zůstat zelený po celou dobu — je to jediná pojistka, že do `commonMain` nepropadne něco androidního.

**Tech Stack:** Kotlin 2.4.10, Ktor client, Room 2.8.4 KMP, DataStore 1.2.1 (`preferences-core`), kotlinx-datetime, Koin 4.x

**Spec:** `docs/superpowers/specs/2026-09-01-kmp-migration-design.md`

**Předchozí plán:** `docs/superpowers/plans/2026-09-01-kmp-faze-0-2.md` — musí být dokončený. Tento plán předpokládá, že aplikace běží na Koinu, `:shared` existuje s iOS canary targetem a charakterizační testy jsou zelené.

## Global Constraints

- Kotlin 100 %, žádný Java kód
- Závislosti vždy přes version catalog `gradle/libs.versions.toml`, nikdy jako string
- `minSdk = 26`, `compileSdk = 37`, Java 17
- Package sdíleného modulu: `com.allergytrack.shared`
- Název databáze `allergy_track.db`, verze 2, migrace `MIGRATION_1_2` — **nesmí se změnit**
- Názvy DataStore souborů `user_preferences`, `onboarding_prefs`, `debug_preferences` a všechny klíče preferencí — **nesmí se změnit**
- Po každém tasku musí platit: `./gradlew :shared:compileKotlinIosArm64` je zelené
- **Tento plán nesmí změnit žádné chování aplikace.** Aplikace je živá na Google Play s reálnými daty.

## Zděděné chyby — nezachraňovat je při migraci

Při analýze kódu se našly tři věci, které jsou dnes rozbité nebo v rozporu s dokumentací. **Migrace je musí zachovat tak, jak jsou.** Oprava je samostatná změna chování a patří mimo tento plán.

1. **Ošetření HTTP 503 je mrtvý kód.** `FoodRepositoryImpl.searchFoodByName()` chytá `Exception` a vrací `emptyList()`. `HttpException` se tedy nikdy nedostane do `FoodLogViewModel:157`, kde se testuje `e.code() == 503`, a `isServiceUnavailable` se nikdy nenastaví. Po přechodu na Ktor musí zůstat stejně mrtvé — nepřidávej propagaci výjimky.
2. **CLAUDE.md tvrdí, že se `HttpException` propaguje do ViewModelu.** Nepropaguje. Dokumentace se opraví ve fázi 9.
3. **`UserPreferencesDataStore.darkMode` má default `false`**, ačkoli CLAUDE.md uvádí `true`. Zachovej `false`.

- [ ] **Step 6: Nahradit java.util.UUID za kotlin.uuid.Uuid**

V `shared/src/commonMain/kotlin/com/allergytrack/shared/domain/model/FoodLog.kt`:

```kotlin
package com.allergytrack.shared.domain.model

import kotlin.uuid.ExperimentalUuidApi
import kotlin.uuid.Uuid

@OptIn(ExperimentalUuidApi::class)
data class FoodLog(
    val id: Uuid = Uuid.random(),
    val timestamp: Long,
    val foodName: String,
    val ingredients: List<String> = emptyList(),
    val allergens: List<String> = emptyList(),
    val latitude: Double? = null,
    val longitude: Double? = null,
    val imageUri: String? = null,
    val notes: String = ""
)
```

**Pozor na dvě věci:**
- Výchozí hodnota `timestamp` byla `System.currentTimeMillis()`, což v `commonMain` neexistuje. Default se **odebírá** — všechna volání musí timestamp předat explicitně. Volající je `FoodLogViewModel`, který timestamp už dnes předává z `DateTimePickerRow`.
- Pokud `Uuid` v Kotlinu 2.4.10 už není experimentální, kompilátor `@OptIn` označí jako zbytečný — pak ho odeber.

Obdobně `SymptomLog.kt`:

```kotlin
package com.allergytrack.shared.domain.model

import kotlin.uuid.ExperimentalUuidApi
import kotlin.uuid.Uuid

@OptIn(ExperimentalUuidApi::class)
data class SymptomLog(
    val id: Uuid = Uuid.random(),
    val timestamp: Long,
    val type: SymptomType,
    val intensity: Int, // 1-5
    val bodyParts: List<String> = emptyList(),
    val latitude: Double? = null,
    val longitude: Double? = null,
    val notes: String = ""
)
```

package com.allergytrack.shared.data.remote

import io.ktor.client.HttpClient
import io.ktor.client.engine.HttpClientEngineFactory
import io.ktor.client.plugins.contentnegotiation.ContentNegotiation
import io.ktor.client.plugins.logging.LogLevel
import io.ktor.client.plugins.logging.Logging
import io.ktor.serialization.kotlinx.json.json
import kotlinx.serialization.json.Json

/**
 * Nahrazuje bývalý provideOkHttpClient + Retrofit.Builder z Hilt NetworkModule.
 *
 * @param logging true = LogLevel.BODY (odpovídá dřívějšímu HttpLoggingInterceptor.Level.BODY
 *                pro Open-Meteo), false = LogLevel.NONE
 */
fun createHttpClient(
    engine: HttpClientEngineFactory<*>,
    json: Json,
    logging: Boolean,
    configure: HttpClient.() -> Unit = {}
): HttpClient = HttpClient(engine) {
    install(ContentNegotiation) {
        json(json)
    }
    install(Logging) {
        level = if (logging) LogLevel.BODY else LogLevel.NONE
    }
}.apply(configure)

```kotlin
package com.allergytrack.shared.data.remote.food

import com.allergytrack.shared.config.AppConfig
import io.ktor.client.HttpClient
import io.ktor.client.call.body
import io.ktor.client.request.get
import io.ktor.client.request.header
import io.ktor.client.request.parameter

/**
 * Supabase REST API nad tabulkou food_products.
 *
 * Autentizace: hlavičky apikey + Authorization s anon klíčem.
 * Dřív je přidával OkHttp interceptor v Hilt NetworkModule; teď se přidávají
 * explicitně u každého requestu, protože Ktor klient je sdílený.
 *
 * Poznámka k lokalizaci: Supabase neakceptuje parametr jazyka. Oba jazykové
 * sloupce jsou vždy v response, výběr probíhá v mapper funkcích.
 */
class SupabaseFoodApi(
    private val client: HttpClient,
    private val config: AppConfig
) {
    /**
     * Lookup podle čárového kódu (EAN). Prázdný seznam = produkt není v databázi.
     * Supabase REST filtr má tvar code=eq.{hodnota}.
     */
    suspend fun getProductByBarcode(barcode: String): List<SupabaseFoodProduct> =
        client.get("${config.supabaseUrl}/rest/v1/food_products") {
            supabaseHeaders()
            parameter("code", "eq.$barcode")
            parameter("select", PRODUCT_SELECT)
            parameter("limit", 1)
        }.body()

    /**
     * Full-text vyhledávání přes PostgreSQL funkci search_products().
     * Prohledává oba jazykové sloupce současně.
     */
    suspend fun searchProducts(
        query: String,
        limit: Int = 20
    ): List<SupabaseSearchResult> =
        client.get("${config.supabaseUrl}/rest/v1/rpc/search_products") {
            supabaseHeaders()
            parameter("query", query)
            parameter("result_limit", limit)
        }.body()

    private fun io.ktor.client.request.HttpRequestBuilder.supabaseHeaders() {
        header("apikey", config.supabaseKey)
        header("Authorization", "Bearer ${config.supabaseKey}")
    }

    companion object {
        /** Sloupce pro barcode lookup — oba jazykové sloupce vždy. */
        const val PRODUCT_SELECT =
            "code," +
            "product_name," +
            "product_name_cs," +
            "allergens_tags," +
            "ingredients_text," +
            "ingredients_text_cs," +
            "brands," +
            "nutriscore_grade," +
            "nova_group," +
            "image_url"
    }
}
```

Room KMP vyžaduje `@ConstructedBy` a `expect object`. Nahraď `AllergyDatabase.kt`:

```kotlin
package com.allergytrack.shared.data.local.database

import androidx.room.ConstructedBy
import androidx.room.Database
import androidx.room.RoomDatabase
import androidx.room.RoomDatabaseConstructor
import androidx.room.migration.Migration
import androidx.sqlite.SQLiteConnection
import androidx.sqlite.execSQL
import com.allergytrack.shared.data.local.database.dao.EnvironmentLogDao
import com.allergytrack.shared.data.local.database.dao.FoodLogDao
import com.allergytrack.shared.data.local.database.dao.SymptomLogDao
import com.allergytrack.shared.data.local.database.entity.EnvironmentLogEntity
import com.allergytrack.shared.data.local.database.entity.FoodLogEntity
import com.allergytrack.shared.data.local.database.entity.SymptomLogEntity

@Database(
    entities = [
        FoodLogEntity::class,
        SymptomLogEntity::class,
        EnvironmentLogEntity::class
    ],
    version = 2,
    exportSchema = false
)
@ConstructedBy(AllergyDatabaseConstructor::class)
abstract class AllergyDatabase : RoomDatabase() {
    abstract fun foodLogDao(): FoodLogDao
    abstract fun symptomLogDao(): SymptomLogDao
    abstract fun environmentLogDao(): EnvironmentLogDao

    companion object {
        const val DATABASE_NAME = "allergy_track.db"

        /**
         * Migrace 1→2: přidává no2, ozone, region a pollenAvailable do environment_logs.
         * SQL je doslova stejné jako v Android-only verzi — mění se jen typ parametru
         * z SupportSQLiteDatabase na SQLiteConnection (Room KMP API).
         */
        val MIGRATION_1_2 = object : Migration(1, 2) {
            override fun migrate(connection: SQLiteConnection) {
                connection.execSQL("ALTER TABLE environment_logs ADD COLUMN no2 REAL NOT NULL DEFAULT 0")
                connection.execSQL("ALTER TABLE environment_logs ADD COLUMN ozone REAL NOT NULL DEFAULT 0")
                connection.execSQL("ALTER TABLE environment_logs ADD COLUMN region TEXT NOT NULL DEFAULT 'UNKNOWN'")
                connection.execSQL("ALTER TABLE environment_logs ADD COLUMN pollenAvailable INTEGER NOT NULL DEFAULT 0")
            }
        }
    }
}

/**
 * Generuje KSP. Tělo zůstává prázdné — "expect" bez "actual" je zde záměr,
 * Room plugin actual doplní pro každý target.
 */
@Suppress("NO_ACTUAL_FOR_EXPECT", "KotlinNoActualForExpect")
expect object AllergyDatabaseConstructor : RoomDatabaseConstructor<AllergyDatabase> {
    override fun initialize(): AllergyDatabase
}
```

- [ ] **Step 2: Vytvořit sdílený helper pro začátek dne**

`FoodRepositoryImpl` i `SymptomRepositoryImpl` mají identický `startOfDay` postavený na `java.util.Calendar`. Vytvoř jeden společný v `shared/src/commonMain/kotlin/com/allergytrack/shared/platform/DateTime.kt`:

```kotlin
package com.allergytrack.shared.platform

import kotlinx.datetime.Instant
import kotlinx.datetime.TimeZone
import kotlinx.datetime.atStartOfDayIn
import kotlinx.datetime.toLocalDateTime

/**
 * Půlnoc dnešního dne v místní zóně, v milisekundách od epochy.
 * Náhrada za Calendar.getInstance() s vynulovanými poli.
 */
fun startOfToday(): Long {
    val tz = TimeZone.currentSystemDefault()
    val today = Instant.fromEpochMilliseconds(currentTimeMillis())
        .toLocalDateTime(tz)
        .date
    return today.atStartOfDayIn(tz).toEpochMilliseconds()
}
```
